## DSH-Android v0.3.12-voice.1 — 免提语音 / Hands-free voice

This is a **test build from a fork**, signed with a new key. Read the install note before using it.

### 新增 / Added

- **唤醒词 / Wake word** — say “Hey DSH” with the phone in your pocket; the app opens and starts
  listening. The phrase is configurable; the default is “Hey DSH”.
- **朗读回复 / Spoken replies** — the assistant's answer is read aloud by the phone's own
  text-to-speech engine, sentence by sentence, and stops the moment you say the wake word again.
- **离线听写 / Offline dictation** — transcription runs on the bundled model, so it works in
  airplane mode.
- One **免提语音** section in Settings → Phone holds all of it. Off by default.

### 重要 / Important — install this one manually

The build is signed with a **different certificate** from the official app, so Android refuses to
install it over an existing DSH. Uninstall the official app first (this deletes its settings and
sessions), then install this APK.

Because the signature differs, the in-app updater cannot install future builds over it either;
download later builds from this repository's Releases.

### 体积 / Size

The APK is about 175 MB: the embedded Node engine, a ~5 MB wake-word model and a ~70 MB
speech-recognition model. Everything runs on the device; no audio is uploaded.

### 已知限制 / Known limitations

- Wake-word detection rate, latency and battery use have **not** been measured on hardware.
- No automatic restart after a reboot on Android 14+; the service resumes when the app is next
  opened.

See `docs/VOICE-WAKE.md` for the design and `docs/CI-RELEASE.md` for how this build was produced.
